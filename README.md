
# Mermail Autonomous Freelance Agent

This repository contains my submission for the Superteam "Build and Demo a Mermail Agent Skill" bounty. 

This project demonstrates a self-sovereign AI agent that runs its own micro-SaaS business. It reads emails, quotes USDC prices, verifies on-chain payments via the Mermail Agent Wallet, and delivers completed work.
